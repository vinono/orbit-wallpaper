Every second of the minute stays on the ring.

A clock that counts instead of sweeping. Each second leaves a number behind, tied to the readout by a string that sways. Design it here, then set it as your phone's live wallpaper.

From browser to home screen

Three steps, no account
01

Design it

Pick a form, palette and placement in the Studio. The phone preview includes a fake home screen so you can see what the icons will cover.

02

Take it with you

Copy the wallpaper link, or send it straight to the app. Every setting travels inside the URL, so there is nothing to sign in to.

03

Set the wallpaper

Install the APK, open it, paste the link and tap Set wallpaper. Android asks you to confirm, and the clock is behind your icons.

Two ways to run it

Same page, same clock
Android

As a live wallpaper

A small WebView wallpaper app, about 200 lines of Java. It loads your link, draws the page into the wallpaper surface, and forwards touches so the strings still move under your finger.

Download orbit-wallpaper.apk
Anywhere else

As a web page or file

Download a single .html file from the Studio. Double-click it, host it, or point the app at your own copy. It never makes a network request.
