# Orbit Wallpaper

An animated clock that counts the minute instead of sweeping it: every elapsed second stays on the ring, tied to the readout by a hair-thin string that sways.

It runs as a web page, exports as one self-contained HTML file, and can be set as an **Android live wallpaper**.

- Site: https://vinono.github.io/orbit-wallpaper/
- Studio: https://vinono.github.io/orbit-wallpaper/studio.html
- APK: https://github.com/vinono/orbit-wallpaper/releases/latest/download/orbit-wallpaper.apk

## Use it on a phone

1. Open the [Studio](https://vinono.github.io/orbit-wallpaper/studio.html) and design the clock. The preview includes a fake home screen so you can see what the icons will cover.
2. Tap **Copy wallpaper link**. Every setting lives inside that URL, so there is nothing to sign in to.
3. Install the APK, open it, paste the link, tap **Set wallpaper**, and confirm in Android's wallpaper picker.

On the same phone you can skip the copy step: **Send to app** opens the app through `orbitwall://set?u=…` with the link already filled in.

Leave the URL empty in the app to use the copy of the page bundled inside the APK. That copy needs no network at all.

## The web page

| File | What it is |
| --- | --- |
| `site/index.html` | Landing page with a live clock |
| `site/studio.html` | Configurator: form, palette, typeface, placement, motion, brightness |
| `site/wallpaper.html` | The wallpaper itself, full bleed, no chrome. Generated by `scripts/build.mjs` |
| `site/assets/*.js` | Clock engine, config encoding, studio wiring |

`site/wallpaper.html` is a single file with the CSS and JS inlined. It opens from `file://`, makes no network requests, and can be hosted anywhere. **Download HTML** in the Studio gives you that same file with your settings baked in.

Configuration travels in the URL hash: `wallpaper.html#c=<base64url JSON>`. Plain query parameters work too, e.g. `wallpaper.html?form=dial&palette=paper&fps=1`.

### Settings worth knowing

| Key | Default | Notes |
| --- | --- | --- |
| `form` | `orbit` | `orbit` `dial` `grid` `chimes` `spiral` |
| `palette` | `phosphor` | `phosphor` `graphite` `ember` `amber` `violet` `paper` |
| `fps` | `30` | `1` or `5` for wallpaper; a plain interval, not rAF |
| `radius` / `offsetY` | `0.34` / `0` | Ring size and vertical placement, relative to the screen |
| `alpha` | `1` | Overall brightness of the marks; lower reads better behind icons |
| `retro` | `false` | Pixelated draw, scanlines, vignette |
| `hour12` | `false` | 12-hour readout |

## How the Android app works

A `WallpaperService` has no window, so a normal View cannot paint into it. The app renders the page offscreen instead:

1. A private `VirtualDisplay` (backed by an `ImageReader`) gives the WebView a real window through a `Presentation`.
2. The newest frame is pulled from the reader and blitted onto the wallpaper surface a few times per second.
3. If a device refuses to create the virtual display, it falls back to drawing the WebView onto a software canvas.

Touches on the home screen are forwarded to the page, so the strings still move under your finger. Redraws default to 2 per second, which keeps the clock cheap on battery.

The app has one screen: a URL field, a preview, and **Set wallpaper**.

## Develop

```bash
npm run build     # rebuild site/wallpaper.html from src/ + site/assets/
npm run serve     # http://localhost:8899
npm run apk       # build the page, bundle it, assemble a debug APK (needs JDK 17 + Android SDK)
```

Deployment is two GitHub Actions workflows:

- `.github/workflows/pages.yml` builds the page and publishes `site/` to GitHub Pages.
- `.github/workflows/android.yml` bundles the page into the app, builds the APK, and attaches it to the `apk-latest` release.
